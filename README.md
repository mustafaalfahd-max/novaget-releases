# NovaGet — التحديثات

هذا المستودع يحوي ملف `version.json` وملفات الإصدارات الخاصة ببرنامج **NovaGet** (مدير تحميل لويندوز) فقط، بلا كود مصدري.

- البرنامج يقرأ `version.json` عند التشغيل، ويعرض التحديث إن وُجد إصدار أحدث، ويتحقق من بصمة SHA-256 قبل التثبيت.
- للتثبيت لأول مرة: نزّل أحدث ملف `NovaGet-x.y.z.zip` من صفحة الإصدارات، فك الضغط في أي مجلد، وشغّل `NovaGet.exe`.
- يتطلب [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (يُثبَّت مرة واحدة).
